# Changelog

All notable changes to this project are documented in this file.

## [1.0.1] - 2026-06-04

### Added
- Chrome Web Store publishing workflow on `main`.
- Repository-hosted privacy policy at `CONFIDENTIALITY.md`.
- GitHub variable `PULSE_BACKEND_URL` for the production backend.
- GitHub secret `CWS_ITEM_ID` for the Chrome Web Store item.
- Release asset publishing for the packaged extension.

### Changed
- Chrome Web Store package now strips `update_url` before upload.
- README now points to the repository privacy policy file.

## [1.0.0] - Initial release

### Added
- Base Pulse Hesias MV3 extension.
- Fullscreen, focus, extension, VM, network, and evidence-capture controls.
